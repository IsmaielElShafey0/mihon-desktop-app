Download for Windows How it works

The real Mihon, in a Windows window

Mihon is a free and open source manga reader for Android. It has no Windows version: its screens, its library and its extensions are all Android code.

Mihon Desktop App doesn't rewrite or change it. It runs the official app, straight from Mihon's own releases, on a small private Android device inside your PC, and shows it in an ordinary window you can resize, maximise and close.

So Mihon works the way it does on a phone, extensions and backups included, and every new Mihon release arrives on its own.

Three parts, one window

Android. Mihon.exe sets up a private Android 17 device with Google's official Android Emulator, trimmed to what Mihon needs. It stays out of sight, runs in about 1.5 GB of memory, and uses Windows' own hypervisor and your graphics card.

Mihon. It downloads the official mihon-x86_64 app from Mihon's GitHub releases, checks it against the checksum GitHub publishes, and installs it. Every time you open it, it looks for a newer release first.

The window. Mihon gets a screen of its own that resizes with the window, so it switches between its phone and tablet layouts like a desktop app. Frames go straight from the graphics card to the window, so scrolling runs at 60 fps.

1

Download and run it

Download Mihon.exe, a single file of about 240 KB, and run it. It isn't code-signed yet, so Windows SmartScreen may say it doesn't recognise it: choose More info, then Run anyway.

It opens a window that says what it will download, then click Accept and install. No administrator rights are needed.

2

Let Android set itself up

Setup downloads about 2.5 GB from Google and GitHub, checks every file against the checksum its source publishes, and starts Android for the first time, which takes a minute or two.

The app installs itself into your user folder and adds a Mihon shortcut to the Start menu. From then on, Mihon opens in about five seconds.

What you need

  • 64-bit Windows 10 or 11 on an Intel or AMD processor
  • 8 GB of RAM. Android takes 1.5 GB of it
  • About 13 GB of free disk space, plus room for chapters
  • The Windows Hypervisor Platform feature. If it's off, the app tells you how to turn it on
  • A graphics card for smooth scrolling. Integrated is fine

Good to know

  • Your library lives inside the Android device, on your PC
  • Each time you close Mihon, its automatic backups are copied to Documents\Mihon for Windows\Backups
  • Backups move between Mihon on a phone and on a PC, both ways
  • Uninstall it from Settings › Apps, like any other app

Questions

The short answers people look for first. For the details, the README covers settings, backups and troubleshooting.

Is there an official Mihon app for PC?
No. Mihon is made for Android only. Mihon Desktop App is an unofficial way to run the official Android app on Windows.
Is it the real Mihon?
Yes. It installs the official mihon-x86_64 app from Mihon's GitHub releases, unchanged, after checking its checksum.
Do I need BlueStacks or another emulator?
No. It sets up its own private Android device with Google's official Android Emulator, trimmed down for Mihon.
Can I bring my library from my phone?
Yes. Make a backup in Mihon on your phone, drag the .tachibk file onto the window, and restore it in More › Backup and restore.
Does it work on Mac or Linux?
No. It needs 64-bit Windows 10 or 11.
Is it free?
Yes, and open source under the Apache 2.0 license, like Mihon.
Why does Windows warn me about it?
Mihon.exe isn't code-signed, so SmartScreen doesn't recognise it yet. Choose More info, then Run anyway.
